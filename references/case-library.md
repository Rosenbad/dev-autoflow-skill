# 任务经验沉淀库（每次任务后必写）

这是本 skill 区别于"通用流程说明"的核心资产。它记录**真实跑过的任务**：需求长什么样、走了哪条通道、结果如何、踩了什么坑。越用越准——下一次遇到相似需求，直接复用这里的模式，而不是重新推理。

## 使用规则

- **Phase 1 开始前**：先读本文件。有相似案例 → 复用其规格要点与通道选择，不重复推理。
- **Phase 3 交付后**：把本次任务追加到案例列表末尾（保持格式一致）。
- 一个任务一条记录，只写关键差异，不写流水账。

## 记录模板

```
### 案例 N：<需求一句话摘要>
- 日期：YYYY-MM-DD
- 需求要点：<3~5 个关键约束>
- 执行通道：<直接执行 / 具体 skill 名 / OrganizeAgent>
- 交付形态：<网页/脚本/表格/文档...>
- 结果：<成功 / 返工后成功 / 失败>
- 教训：<踩的坑、下次要提前确认的点；没有则写"无">
```
